# 시연 데이터 출처

교육용 제공 파일 `pjt_01/skeleton/data/books_500.json`의 16개 간격 항목 중 앞 30권을 사용합니다. 원본의 알라딘 도서 제목·저자·설명은 HTML 엔티티만 해제했고, 10점 만점 customerReviewRank는 2로 나누어 5점 만점으로 변환했습니다. 0은 원본값이며 실제 평가가 없을 수 있습니다. 출처 링크를 sample_books.json에 함께 기록했습니다.

교육 과제 시연을 위한 자료이며 별도 수집 또는 AI 생성 데이터가 아닙니다. 도서 데이터의 권리는 원 저작권자에게 있으며, 외부 서비스의 상업적 데이터셋으로 재사용하기 전에는 별도 이용 조건 확인이 필요합니다.

`python manage.py seed_books`로 추가합니다. 반복 실행 시 같은 제목·저자는 추가하거나 수정하지 않습니다. 기존 사용자 입력 자료를 덮어쓰지 않습니다.

표지는 제공 자료의 cover URL에서 내려받은 알라딘 이미지를 정적 파일로 포함했습니다. 원본 이미지 URL은 각 항목의 cover_source_url에 기록했습니다. seed_books는 기존 레코드의 표지가 비어 있을 때만 제공 표지 경로를 보충하며, 제목·저자·소개·평점은 덮어쓰지 않습니다.
